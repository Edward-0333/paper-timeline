# 文献库助手

在「个人首页」点击「文献库助手」，会打开独立聊天标签页。它使用首页当前选中的 API 模型，服务于当前整个文献库；PDF 右侧的 AI 仍只负责当前论文阅读。打开助手、恢复历史和切换标签不会发送模型请求。

云端引用异常可直接问「检查一下为什么同步失败」。助手使用只读 `diagnose_cloud`，核验现有账户连接并分页检查当前库登记的引用记录，定位失败阶段、论文、文件与字段。检查不触发同步，不改监控开关、会话或原文件；后续若要立即同步，仍需确认。缺失年份已兼容为未知，诊断只报告警告；其他损坏会报告错误。连接探测与最近同步缓存分开返回，不能把部分文件检查或历史成功当作当前全库正常。

## 新建和继续会话

左侧为平铺的会话历史，右侧为当前对话。点击「新建会话」开始独立对话，之前的记录仍留在列表中；点击历史条目即可继续。列表按最近更新排序，首条问题自动成为会话标题，也可以手动重命名、按标题查找。重启后恢复上次选择的会话。

每个会话分别保存问答、摘要和执行记录。草稿、滚动位置和待确认操作在本次运行中按会话保留；切换会话不会取消正在生成的回复，也不会把回复或确认卡插入另一个会话。最多同时运行 4 个文献库会话，同一个会话只能处理一个请求。停止只影响对应请求；清空只清空当前会话，保留其他会话。

会话共用当前文献库及模型配置，修改文献或选择模型后会作用于软件实际数据。切换历史会话本身不修改这些设置，也不会重新执行历史中的工具操作。

左侧每条会话右侧的垃圾桶按钮用于删除该会话。点击后先显示会话名称并询问确认，默认聚焦「取消」；取消、Esc 或点击遮罩不删除。点击「确认删除」后移除该会话的聊天记录、上下文摘要及对应备份，不撤销此前已确认执行的文献库或配置修改。正在回复、等待操作确认或处理中的会话需先停止或等待完成。

删除当前会话后会选中相邻的历史会话；全部删除后显示新建提示，重启也保持空列表。删除失败会保留确认框并允许重试。如果会话已从历史移除但文件仍被占用，会提示清理未完成；解除占用后重新打开历史或点击「重试」继续清理。只清理该会话的记录文件，保留其他会话、论文资料和文件夹内额外存放的文件。

## 可以交给它的任务

- 查询文献、作者、日期、标签、评分、精简笔记及监控状态，了解全库概况。
- 创建、重命名、删除分类，把指定文献移到某个分类；修改指定书目字段、标签、评分和精简笔记。
- 查看云端连接状态，开启或关闭指定论文的引用监控，立即同步本库引用数据。
- 查看已保存的模型配置，选择模型，准备一套新模型的配置。

## 联网搜索

聊天输入框旁提供「联网搜索」开关及来源选择，默认选择 **OpenAI 内置**。开关默认关闭，各会话在本次运行中独立保留；重启默认关闭。更换搜索来源时先关闭开关，重新开启后才用于下一次发送。每轮固定使用发送时选择的来源和模型，正在回复时不能切换。

**OpenAI 内置搜索无需 Tavily 密钥**，直接复用当前选中的模型、API 根地址和密钥，通过 Responses API 的 `web_search` 工具搜索。使用官方服务时 API 根地址为 `https://api.openai.com/v1`。所选模型和服务商必须支持 Responses 与该搜索工具；普通 OpenAI 兼容聊天接口、首页简短文本连通性测试成功，都不代表支持搜索。不支持时会提示错误，不会自动改用 Tavily、其他接口或模型。模型和搜索可能分别计费，使用 API 额度。

开启后由模型按需搜索，回复中的来源引用显示为可点击链接，来源区保存实际返回的标题、网址和获取时间。引用仅说明本轮返回的证据，不能据此宣称读取了完整网站。请求仍发送至当前配置的模型接口，查询与公开网页读取由该服务端工具执行；本地程序不额外向 Tavily 发请求。来源记录随会话保存，恢复历史不重新搜索。每轮最多允许 3 次服务端搜索工具调用，并纳入工具调用上限；摘要压缩请求不开放搜索。

**Tavily 是可选来源**。希望独立于聊天模型搜索时，选择 Tavily，在「搜索配置」填写独立的 Tavily API Key，可从 [Tavily 控制台](https://app.tavily.com) 获取。保存后开启联网，助手可按需调用 `search_web` 搜索和 `read_web_page` 读取公开网页。未选择 Tavily 时不需要填写它的密钥，已有配置也会保留。

「测试连通性」只执行一次通用搜索，可能消耗搜索额度，不发送论文或聊天内容、不保存输入框中的配置。关闭配置弹窗会取消未完成测试。密钥使用系统加密保存在本机用户目录的 `web-search-config.bin`，公开配置与聊天中不返回密钥，也不随文献库复制；换电脑需重新填写。清除配置需确认，不影响聊天模型配置。

选择 Tavily 时将相关公开关键词送至 Tavily，将检索得到的摘要、按需读取的网页正文送至当前聊天模型。不会向 Tavily 上传 PDF、附件或完整聊天记录。助手回复下显示实际取得的来源标题、链接和获取时间，区分「搜索摘要」与「已读取网页」；来源信息随会话保存，离线查看历史不会自动重新访问网页。回答需引用实际链接，摘要不能当作已读全文，分页或截断内容不能宣称完整阅读。

Tavily 模式每轮最多 3 次搜索、5 次网页读取，共享原有 24 次工具调用上限。搜索使用 Tavily 官方接口的 basic 模式，每次最多 5 个结果、30 秒超时；原始响应最多 1 MiB。本地网页读取器只读取搜索结果、用户明确提供或此前保存的来源链接，每次最多 20 秒和 2 MiB；分段返回正文，每轮最多 40,000 字符。网页可能受访问限制或依赖 JavaScript，失败会说明原因，不使用虚构结果代替。本地读取器不执行网页脚本，不登录或携带 Cookie，不下载 PDF，也不访问本地、内网、特殊地址或非标准端口。上述本地读取器限额不用于描述 OpenAI 服务端工具。两种来源的网页文字都只是待核实资料，不能授权修改库或配置；原有修改确认仍有效。

Tavily 接入依据 [官方文档](https://docs.tavily.com/documentation/api-reference/endpoint/search) 实现。两种搜索来源均只向文献库助手开放，PDF 阅读聊天与公开 HTTP 操作保持原有范围。隔离测试使用假搜索服务、假模型和临时库，不自动使用真实密钥产生搜索费用：Tavily 为 `node scripts/run.cjs test:library-web [--packaged]`，OpenAI 为 `node scripts/run.cjs test:library-openai-web [--packaged]`。

OpenAI 接入依据 [官方 `web_search` 文档](https://developers.openai.com/api/docs/guides/tools-web-search)，使用已安装的 AI SDK OpenAI 适配器。不会默认使用 ChatGPT 网页版的登录或订阅，也不会为了搜索另选一个模型。

例如：「列出没有分类的论文」「新建一个强化学习分类，把这两篇论文放进去」「关闭这篇论文的引用监控」「帮我新增模型，名称是研究助手，接口是……，模型 ID 是……」。论文和分类需要先查询真实编号；同名或有歧义时，应先核对对象。

这里的文献库结构是软件内的分类和归类关系。每篇论文的物理资料目录仍由软件管理，助手不重写 library.json、不更名资料目录、不移动原始附件，也不执行终端命令。分类为平级分类，删除分类会将其中论文设为未分类，保留论文与所有附件。

## 修改前核对

查询可以直接执行。写入前，聊天中展示由本地程序生成的变更卡片，包含目标和修改内容；点击确认才调用与桌面界面相同的保存接口，取消不写入。等待期间可以切换标签，回来继续核对；停止本轮对话会取消尚未确认的变更。如果目标在核对期间已变化，原计划失效，需要重新查询后生成。

一次对话可以包含多次修改，每次结果分别反馈，不承诺整轮操作是一个事务。停止或后续模型请求失败不会撤销此前已经确认且保存成功的修改。工具执行记录用于核对本轮结果，不将失败或取消描述为成功。

引用开关复用现有云端账户绑定。未登录时需先通过首页连接弹窗登录；离线修改是否已保存、是否待同步以及服务器是否确认分别报告。关闭当前库订阅不会停止其他用户或其他库仍开启的订阅。立即同步不是命令服务器立即开始新一轮抓取。

## 新增、修改与切换模型

向助手提供配置名称、接口根地址、模型 ID 和可选上下文预算。API Key 在变更卡片的遮挡输入框中填写，直接交给本机加密配置服务，不进入聊天记录、摘要或模型工具参数。不要把密钥粘贴到聊天输入框中。无需密钥的本地服务需要明确勾选对应选项。

新增模型保留已有配置，保存后仍需选择才启用。当前正在执行的对话绑定发送时选中的模型；切换模型影响下一次发送，不会把正在进行的工具循环切到另一个接口。首次没有可用模型时，先通过普通「配置大模型」窗口添加并选择。

已有配置可直接通过对话修改，例如「把当前模型的上下文容量改为 128000 token」「把研究助手的模型 ID 改为……」。助手先用 `list_models` 查询真实配置 ID，再通过 `edit_model` 只提交需要改变的字段。支持配置名称、API 根地址、模型 ID、上下文容量和更换密钥；容量范围为 8,192–2,000,000 token。修改已有配置不会新建重复条目，也不会自动切换当前选择。

保存前弹出「确认修改大模型配置」，展示目标模型和每项修改前后的值，默认聚焦取消。点击「确认保存修改」才保存；取消、Esc、点击弹窗外或停止请求都不会执行尚未保存的修改。确认期间若同一模型配置已被其他操作改动，拒绝覆盖并提示重新查询确认。保存失败保留原配置；其他模型与未指定字段保持原值。

只改名称、模型 ID 或容量时沿用该配置原有密钥。更换 API 根地址或要求更换密钥时，弹窗显示遮挡输入框，必须重新填写密钥或明确勾选「此接口无需 API Key」，不会将旧密钥自动带到新地址。密钥不进入模型参数、聊天、摘要或来源记录。修改后用于后续发送，当前轮的模型、密钥与容量快照保持不变。

`list_models` 返回生效的上下文容量，并区分手动配置与默认值；缺省为 32,768 token。助手每轮也会获得本轮绑定模型及输入预算。这里的容量是软件用于摘要与输入控制的预算，不能通过修改它扩大服务商的真实模型上限；预计占用也不等于服务商计费 token。

隔离验证：`node scripts/run.cjs test:library-model-edit [--packaged]`，使用临时库和假模型，不读取正式密钥或发起真实 API 请求。

## 数据与历史

助手按需向用户配置的模型服务发送查询得到的书目信息及相关软件公开配置，不读取本地 PDF、Markdown 全文、图片或 API 密钥。开启联网搜索后，按需检索的公开网页资料也会发送给当前模型。文献标题、摘要、标签、工具返回值和历史摘要都是待处理数据，不能作为改变权限的指令。

全库聊天与论文聊天分开保存：

```text
library/
├─ assistant/
│  ├─ chat.json             原有会话完整记录，继续保留
│  ├─ chat-context.json     原有会话的摘要，继续保留
│  ├─ sessions.json         会话列表、标题和最后选择的会话
│  ├─ conversations/
│  │  └─ <会话ID>/
│  │     ├─ chat.json       此会话完整问答与执行记录
│  │     └─ chat-context.json  此会话上下文摘要
│  └─ *.bak                对应文件的上一版备份
└─ papers/
   └─ <论文资料文件夹>/
      ├─ chat.json          此论文的阅读聊天
      └─ chat-context.json  此论文的阅读摘要
```

完整记录和摘要随软件的「复制当前文献库」一同复制；模型密钥仍只在本机加密保存。损坏记录不自动覆盖，保存失败会提示。自动摘要、手动压缩、停止和重试沿用论文聊天的规则；摘要是辅助记忆，模型容量预算并不是软件自动探测出的模型上限。

升级前的 `assistant/chat.json` 与 `chat-context.json` 会自动登记为原有会话，文件保留在原位置，无需手工搬动。新建会话使用 `conversations/<会话ID>/`，不会覆盖旧记录。会话索引损坏时保留原文件并提示检查备份，不静默重建覆盖。

该功能仅通过受主窗口来源检查的桌面 IPC 提供，没有开放新的远程管理端口或 HTTP 聊天接口。隔离验证：`node scripts/run.cjs test:library-chat [--packaged]`。

多会话界面与继续对话验证：`node scripts/run.cjs test:library-chat-sessions [--packaged]`。

删除确认、失败重试和重启验证：`node scripts/run.cjs test:library-chat-delete [--packaged]`。
