# 内置 Markdown 笔记

点击文献列表的「MD 笔记」图标、详情中的笔记按钮或时间线 MD 文件标签，即可在 Paper Timeline 内阅读笔记。顶部新增「MD：论文标题」标签，长标题省略，悬停查看完整名称。不同论文各开一个标签，同篇复用已有标签；笔记、PDF、引用详情和首页分类列表可以同时保留在顶栏。

笔记属于具体论文，有无 PDF 不影响阅读。还没有笔记时，先在文献详情中选择「添加 Markdown 笔记」，把已有 UTF-8 `.md` 文件复制到文献库，每篇一份，最大 10 MB。软件编辑的是库中副本，原始导入文件保持原样。

## 阅读与编辑

打开后默认显示阅读模式，可渲染标题、加粗、列表、引用、表格、代码块及公式。点击「编辑」后，左侧显示实时预览，右侧编辑 Markdown 源码，工具栏可插入常用格式，并提供撤销和重做。源码编辑采用 Vditor 4.0.1；阅读与预览采用 Streamdown，代码高亮和公式所需资源随程序打包，离线可用。

点击「保存」或按 Ctrl+S（macOS 为 Command+S）保存修改，底部显示保存状态。切换到其他论文或页面、关闭工作区标签、退出软件及复制文献库前，也会等待当前笔记保存。保存失败时保持当前页面和草稿，解决问题后重试。强制结束进程或断电仍可能丢失尚未保存的修改。

「默认软件打开」继续使用电脑上关联的 Markdown 软件。若两边都在编辑同一份笔记，请先在外部软件保存，再在 Paper Timeline 点击「重新读取」。

## 保存位置和外部修改

笔记仍保存在当前论文资料文件夹中，结构没有变化。

```text
library/
├─ library.json
└─ papers/
   └─ <该论文的稳定资料文件夹>/
      ├─ original.pdf       PDF 原文（可无）
      ├─ notes.md           当前笔记
      ├─ notes.md.bak       上一次保存前的完整笔记
      ├─ annotations.json  PDF 阅读记录（可无）
      ├─ parsed/           MinerU 全文结果（可无）
      └─ citations/        引用缓存（可无）
```

软件按论文 ID 和已登记的资料文件夹定位笔记，不根据标题猜路径。详情「更多操作 → 打开资料文件夹」可以查看实际位置；修改论文标题不会移动文件夹。保存笔记不会修改 PDF、标注、书目、标签、评分，也不会改写初次导入笔记的来源哈希。重复导入原始文件仍会保留库中编辑。

每次保存都会检查打开时的文件版本。若外部软件已改动 `notes.md`，软件提示冲突并保留当前草稿，不覆盖外部文件。请复制需要保留的草稿，点击「重新读取」，确认后加载磁盘中的最新版本，再合并需要的内容。有未保存修改时，「重新读取」会先确认，默认选中「取消」。没有强制覆盖接口，也不会静默把备份恢复到原文件上。

文件缺失、损坏、编码无效、超出大小限制，或文件及目录使用链接时，软件会报告错误并保留文件，不会创建空白笔记覆盖。需要恢复时，请先保留当前文件及 `.bak`，核对内容后再处理。

## 图片和链接

此版专注文字笔记。图片引用仍保留在 Markdown 源码中，阅读和预览显示图片占位，不自动读取本地图片或请求网络图片；Obsidian 附件目录及 `![[…]]` 链接尚未适配。HTML 不执行。HTTP(S) 网页链接只有在点击后才由系统浏览器打开，笔记内容不会自动发送到 AI 接口。

编辑器只通过受主窗口来源检查的桌面接口访问当前论文登记的笔记，不接受任意文件路径。公开 AI HTTP 接口仍提供原来的 `notes.attach` 和 `notes.get`，本次未开放 AI 笔记修改操作。

## 换电脑与验证

使用「文献库设置 → 复制当前文献库」会先保存当前阅读内容，再复制和校验完整 `papers/`，包括笔记及其备份。手动迁移时也请复制完整 `library/`，不要只拷贝 EXE 或 `library.json`，也不要同时编辑同一个库的两个独立副本。

开发验证使用 `.test-data/` 内的隔离文献库，不修改正式资料。

```sh
node scripts/run.cjs test
node scripts/run.cjs build
node scripts/run.cjs test:notes
node scripts/run.cjs test:notes --packaged
```

后端验证覆盖原子保存及备份、并发编辑、外部修改冲突、丢失响应后的重复保存、重启恢复、无效 UTF-8、链接及导入身份保留。桌面验证覆盖内部打开、阅读与编辑、保存、标签切换、冲突处理及本地资源加载。
