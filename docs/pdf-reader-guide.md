# 内置 PDF 阅读器

阅读页顶部「打开资料文件夹」可直接打开当前论文的资料目录，包含该论文的 PDF、笔记、标注、聊天和解析结果等。操作保留当前页码、缩放和标注；打开失败会显示独立提示，可重试。

阅读页顶部的「标签」可查看、添加、编辑或删除当前论文的分类标签，沿用文献库的统一颜色与删除确认。「精简笔记」可用一两句话评价论文，支持保存、修改或留空清除，Ctrl+S 可保存；与详情和时间线共用同一份笔记。操作这些入口不会重新加载 PDF 或改变标注、页码和缩放。精简笔记保存在库索引的 `briefNote`，独立于 Markdown 文件。

点击列表的红色 PDF 图标、时间线的 PDF 文件标签、详情的「打开 PDF」，或在列表双击论文，即可在软件内阅读原文。打开另一篇论文会新增阅读标签，原来的标签保留；重复打开同一篇会切回已有标签。「文献库」返回原有列表或时间线，顶部阅读标签仍可点击返回各篇论文。阅读器右上角仍有「默认软件打开」。

顶部左侧依次为「个人首页」「文献库」和已打开的工作区标签，新论文接在「文献库」右侧的已有标签后，与导航位于同一行。每个阅读标签固定为 200 像素宽，显示论文标题，长标题用省略号截断，悬停可看完整名称。标签较多时在中间区域横向滚动，首页、文献库和右侧操作按钮保持可见，当前标签会自动滚动到可见位置。点击标签右侧的 × 单独关闭；关闭当前标签后切换到相邻工作区标签，全部关闭后回到文献库。标签获得焦点后可用左右方向键切换、Home/End 跳到首尾、Delete 关闭。

首页分类列表及点击「被引数」打开的引用详情也使用顶部标签，与 PDF 阅读标签共存，切换不会覆盖已打开的论文。引用详情展示本地缓存中引用该论文的文献，每页 50 条，单击条目可看摘要等信息；同篇复用已有引用标签，各篇独立记住页码与选中项。进入引用列表或返回 PDF 前仍执行阅读记录保存，失败时保留当前阅读页。详见 [云端引用监控](cloud-monitoring-guide.md)。

每篇论文分别恢复已保存的标注、页码和缩放；切换或关闭前先完成保存，保存失败会保留当前论文和标签，重试成功后再切换。阅读时只加载当前论文的 PDF 引擎，避免随标签数量同时启动多套引擎。

阅读器右上角搜索、评论旁的「AI」打开当前论文阅读 Agent，三种侧栏相互切换。使用首页配置的大模型，可在用户发送后按需调用限定于当前论文的工具，运行本机 MinerU、读取全文和笔记、搜索文字、查看解析图片或原始 PDF 页面。资料内容可能随工具请求发送到已配置接口，打开面板不联网。成功对话与资料引用保存在每篇论文的 `chat.json`，可在重启后恢复；草稿仅保留在运行内存中。详见 [模型配置与论文 Agent](model-api-guide.md)。

在 PDF 页面上按住 Ctrl（macOS 为 Command）滚动鼠标滚轮可缩放。普通刻度每步最多变化 5 个百分点，例如 100% → 95% → 90%，反向滚动按相同步长放大；高精度滚轮的小幅移动保留更细的变化。工具栏「＋／－」同样每步调整 5 个百分点，所有缩放范围内均使用相同步长，不再随倍率加大而突然跳跃。缩放以鼠标所在位置为中心，范围为 10%–500%；不按 Ctrl 的滚轮仍用于正常翻阅，不改变整个软件界面的缩放。

在阅读器顶部选择「批注」，点击「高亮」或「下划线」，然后按住鼠标选择文字，可跨行标记。也可以先选择文字，再从浮动菜单添加标注。点击已有标注可调整颜色、添加评论或删除；工具栏提供撤销和恢复。工具栏及右侧面板属于当前 PDF，不会改变论文的分类标签、评分或 Markdown 笔记。

标注修改后会自动保存，底部显示保存状态。切回文献库、关闭阅读标签或退出软件时会先完成保存。保存失败时阅读器会显示错误，保留未保存的修改，可点击「重试保存」；请成功保存后再退出。强制结束进程或断电仍可能丢失最后一瞬间的修改。

每篇 PDF 的标注、最近页码和缩放比例保存在 `library/papers/<资料文件夹>/annotations.json`，更新时保留上一版 `.bak`。同一文件夹中的 `original.pdf` 内容不变；原文自带的批注也会加载。标注文件绑定 PDF 内容，若外部替换了原文或标注损坏，会提示核对并保留文件，不会覆盖原标注。详情「更多操作 → 打开资料文件夹」可查看；目录通过稳定 `storageFolder` 关联，不随论文标题修改。旧布局及阅读记录会自动升级，见 [文献库布局与迁移](library-layout-guide.md)。

使用「文献库设置 → 复制当前文献库」会复制并校验完整 `papers/`，包括每篇的 `annotations.json` 及其备份。手工换电脑时也请复制完整 library 文件夹。不要同时编辑同一个库的两个副本。此版本的标注只在 Paper Timeline 内显示，默认软件打开的是原 PDF，尚不提供导出带标注 PDF；阅读器本身没有 OCR，扫描版没有文字层时不能直接选中文字，可用详情中的 MinerU 另行转换。加密或不兼容的 PDF 可使用默认软件打开。

阅读器、PDFium 引擎和中文后备字体随软件打包，阅读和标注不依赖网络服务，不上传 PDF 或标注。单篇原文限制 100 MB，单篇标注 JSON 数据限制 20 MB。

技术集成固定使用 `@embedpdf/react-pdf-viewer@2.15.1`，阅读组件按需加载。许可见 [第三方说明](../THIRD_PARTY_NOTICES.md)。

开发验证：

```sh
node scripts/run.cjs test
node scripts/run.cjs build
node scripts/run.cjs test:reader
node scripts/run.cjs test:reader --packaged
```

测试使用 `.test-data/` 中的隔离文献库，验证鼠标多行高亮、下划线、改色、删除/撤销、原有批注、多标签切换与关闭、标题省略及横向滚动、保存失败重试、关闭前保存、重启恢复、移动文献库和原文保护，不使用正式文献库。
