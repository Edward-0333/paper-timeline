# API 大模型配置

首页的 [文献库助手](library-assistant-guide.md) 可查询模型列表、新增配置、修改已有配置或请求切换模型。已有配置可修改名称、接口、模型 ID 和上下文容量；保存前弹窗展示修改前后的值，确认后才保存，取消或 Esc 不写入。修改接口地址或密钥时在本地遮挡输入框重新填写 API Key，密钥不发给聊天模型，也不保存到聊天历史；仅修改容量等公开字段时保留原密钥。新增或修改均保留其他配置且不自动选择；确认期间配置发生变化会拒绝覆盖，当前请求仍使用发送时的模型与容量快照，后续发送使用新值。

个人首页的「API 大模型」卡片显示当前模型。点击「配置大模型」先查看已保存的模型列表，当前生效的条目标有「当前使用」。选中目标行并点击「选择」后，下一条消息或重试就会使用它。正在生成的回答继续使用发送时的模型。

点击「添加」打开空白表单，填写配置名称、接口地址、模型 ID 和密钥。保存后返回列表并选中新条目，点击「选择」才会启用，包括首次添加的模型。要修改已有配置，先选中条目，再点击「编辑」。删除当前模型后，软件会启用剩余列表中的第一套。

在编辑页更改模型 ID 或接口地址后，可以「另存为新模型」，保存后返回列表。要更新原条目，可点击「替换原配置…」并确认。

## 论文阅读 Agent

点击阅读器搜索、评论旁的「AI」，右侧显示聊天面板。可输入消息、发送、停止生成、失败后重试或清空对话；Enter 发送，Shift+Enter 换行。未配置模型时可从面板「配置大模型」打开同一设置弹窗。搜索、评论和 AI 共用同一个右侧区域。

拖动 AI 面板左侧边界可调整宽度，调整结果保存在本机，切换论文、关闭面板或重启后仍保留。窗口变小时自动限制宽度，给 PDF 留出阅读空间；边界也可用左右方向键微调。

AI 回答使用 [Streamdown](https://github.com/vercel/streamdown) 显示，支持标题、加粗、列表、引用、表格和代码块，中文加粗兼容紧邻标点的情况，旧聊天记录同样适用。Shiki 提供代码语法高亮，代码块右上角可复制完整代码；宽表格和代码块可单独横向滚动。

可用鼠标选中聊天文字后按 Ctrl+C 复制，聊天面板保留键盘焦点，避免触发 PDF 的复制快捷键。每条消息右上角也有复制按钮，复制该条原始内容（AI 回复保留 Markdown），失败可重试。鼠标停在公式、表格或代码块上时，竖向滚轮可继续滚动聊天记录；内部长内容优先滚动，达到边界后继续外层聊天，聊天边界不带动 PDF。

数学公式由 KaTeX 本地排版，支持 `$...$`、`$$...$$`，以及模型常用的 `\(...\)`、`\[...\]`；后两种只在显示时转换，代码中的同类符号保留原样。公式样式、字体、代码语言与主题随软件打包，渲染不请求 CDN。当前仍在模型完整回复后显示，接入 Streamdown 不改变聊天接口的请求方式。

记录仍保存原始 Markdown；用户输入保持原样。网页链接点击后用系统默认浏览器打开，模型给出的 HTML 不执行，图片地址不自动加载。阅读器内单独挂载带前缀的 Streamdown 样式，保留原有 PDF 和侧栏功能。

面板显示当前论文名称和「工作目录」，展开后可查看关联文件路径。工作目录为当前论文的资料文件夹（`library/papers/<资料文件夹>/`），原文、笔记、标注和解析结果集中存放在这里。发送「现在的工作目录是什么」时，模型可以依据这份上下文回答。该文件夹由稳定 `storageFolder` 关联，标题修改不会重命名；详情「更多操作 → 打开资料文件夹」可查看。旧库的升级和搬库规则见 [文献库布局与迁移](library-layout-guide.md)。

只在发送、重试或点击「立即压缩」时向已保存模型地址提交资料。发送和重试包含当前会话、论文身份和目录上下文；手动压缩只整理历史，不调用论文工具。主进程重新绑定当前论文，工具不接受其他论文 ID、任意路径、网络图片地址或终端命令。模型可以自行选择以下工具，按问题多次查阅资料：

| 工具 | 功能 |
| --- | --- |
| paper_info | 查看当前论文及解析状态 |
| prepare_fulltext | 复用有效结果，或启动本机 MinerU 并等待，默认 basic；用户明确要求重新解析时可使用 force |
| read_text | 按行读取全文、笔记或标注；长文返回 nextLine，可继续读取 |
| search_text | 关键词查找并返回上下文及行号 |
| list_images | 分页列出当前有效解析版本中的图片 |
| view_image | 发送指定图片的实际内容 |
| view_pdf_page | 本地渲染指定原始 PDF 页面并发送图片 |

例如发送「分析这篇论文的主要贡献，核对图1」后，AI 可以先准备全文，再读取文字、定位图1、查看图片；追问时可以重新搜索或查看原始页。文字工具返回内容版本哈希和行号，图片及页面提供来源引用。回答下方可展开「资料查阅记录」。资料中的文字、标题和图片均作为数据，不作为指令。

读取的文字、笔记、标注及查看的图片会发送至已配置模型接口；原始 PDF 仅在本地转换或渲染，不直接上传 PDF 文件。图像请求使用图片内容而非本地路径，不自动拉取 Markdown 中的网络链接。没有全文、转换失败或模型不支持图片/工具时会反馈限制。不会修改原文、笔记、阅读标注或其他论文。所有工具在桌面主进程执行，不向 AI HTTP 接口公开。

发送前先把用户问题保存到当前论文 `chat.json`，成功回答及工具步骤、来源引用随后追加保存，上一版保存在 `.bak`。不再为了模型上下文限制删除早期问答，失败或停止也保留已经提交的问题。关闭阅读标签或退出后重新打开，会从文件恢复对话；打开及恢复过程不联网。草稿只保留至退出。记录不保存图片二进制、整份工具返回或密钥；后续问题需要时重新读取本地资料。随完整 library 复制可保留对话，模型配置需在新电脑重填。清空会保存空记录并失效旧摘要，备份仍保留；损坏记录不自动覆盖，保存失败时保留当前回答并提示。旧版本已经裁掉的问答无法凭摘要功能自动恢复。

### 软件管理的摘要压缩

每套模型可填写「上下文容量（token）」，范围 8192–2000000。旧配置默认采用保守预算 32768，未知模型同样使用此值；它不是软件自动探测出的模型容量，应按服务商说明调整。上下文占用通过文本估算，预留模型输出、系统说明、工具及图片空间，不是服务商精确计费 token。容量配置随该模型保存在本机加密设置中，切换模型后重新计算预算。

发送前，软件使用现有有效摘要和近期问答检查预算。超过预算时，用当前选中且已绑定的模型分批整理早期问答，保留研究目标、已确认结论、重要数字、限制、未解决问题及来源位置；近期消息和当前问题尽量保留原文。整理会额外调用模型，可能产生费用和等待时间。点击「立即压缩」可主动整理，不添加聊天回答、不清除草稿。摘要可以展开查看，完整历史按每次 50 条逐步加载，界面显示预计占用及摘要覆盖范围。

摘要保存在同一论文文件夹的 `chat-context.json`，包含覆盖消息数、正文前缀校验、模型和时间，上一版为 `.bak`。普通文本摘要可跨模型使用，不启用 OpenAI 专属服务端压缩。换成容量更小的模型后，必要时再次整理；摘要只作为历史线索，关键证据可由工具重新读取。资料和摘要始终作为数据，不能扩大论文工具权限。

工具循环每一步也会检查预算，精简可重读的较早工具结果并保留调用配对和来源位置。当前问题、最新资料或图片仍然放不下时，会提示缩小范围或检查模型容量，不静默截断问题。摘要失败、停止或保存异常保留完整历史与已有摘要；不会通过删除原始聊天来继续发送。清空聊天时先失效摘要；旧摘要校验不符时不使用，损坏文件不自动覆盖。

执行层使用 `ai@7.0.150` 管理论文工具，使用 `@ai-sdk/openai@4.0.101` 发送 Responses 请求，使用 `@ai-sdk/openai-compatible@3.0.77` 发送 Chat Completions 请求。两个适配器都直接连接用户配置的模型服务。DeepSeek 官方接口使用非思考模式完成工具循环。

文献库助手另外提供可选的「OpenAI 内置」联网搜索：开启时该轮使用当前配置的 Responses API 和 `web_search`，不需要 Tavily 密钥；所选模型与服务商须支持这两个能力。不支持时提示错误，不自动切换搜索服务或模型。关闭搜索后沿用原有模型路由；论文阅读 Agent 不因此增加联网权限。详见 [文献库助手](library-assistant-guide.md#联网搜索)。

每轮论文分析最多12次模型步骤、24次工具执行，摘要整理有独立的分批上限；单次模型请求120秒、整轮30分钟（含摘要和等待解析），每次分析输出最多4096令牌，响应最多1MiB。单次文字读取最多60000字符，每轮最多240000字符；图片最多6张、合计12MiB，解析图片会缩放至最长边2000像素，PDF页面最长边1800像素。长文需分段读取，超过预算可继续提问。单条聊天20000字符，本地归档安全上限10000条/1000万字符/64MiB，超限保留原文件并报错，不自动删历史；这不是发送给模型的上下文容量。最多4篇论文并发，同一篇同时只处理一个发送或压缩请求。错误不自动重试，不跟随重定向。

停止或退出会中止本轮模型请求（含摘要）及本轮启动的 MinerU 任务；此前已在运行的手动转换继续独立运行。切换文献库先停止 Agent、等待记录保存，再复制或切换。验证使用隔离假服务，不读取真实模型配置或发送正式论文：`node scripts/run.cjs test`、`node scripts/run.cjs test:chat [--packaged]`、`node scripts/run.cjs test:chat-compaction [--packaged]`。

## 测试连通性

首页测试通过 Chat Completions 发送简短文本。GPT-6 Astra、Sol、Terra 和 Luna 系列在 PDF 阅读器中自动通过 Responses API 调用论文工具。OpenAI 官方 Base URL 填 `https://api.openai.com/v1`，程序拼接 `/responses`。第三方服务提供这些模型时也需要支持该端点。软件设置 `store: false`，在本轮工具调用中传回加密推理项。详见 [OpenAI 模型指南](https://developers.openai.com/api/docs/guides/latest-model?model=gpt-6-astra)。

其他模型沿用 Chat Completions 工具接口。服务明确拒绝输出长度参数时，软件在本轮尝试一次兼容参数。服务指出模型权限、工具格式、图片或上下文长度问题时，聊天窗口显示对应提示。

填写接口地址、模型名称和密钥后点击「测试连通性」，无需先保存。测试使用当前填写值，密钥留空时仅复用同一完整 Base URL 的已保存密钥；切换地址须重新填写。选择无需密钥时不发送鉴权头。测试不保存或更改配置，修改字段后会清除旧测试结果，成功状态只代表本次请求通过。

测试通过主进程向 `${Base URL}/chat/completions` 发送固定的简短 user 消息，请求指定模型，非流式、最多 16 个生成令牌。优先使用 `max_completion_tokens`，仅在明确不支持该参数的 HTTP 400 时再尝试一次 `max_tokens`，不对鉴权、限流或服务故障自动重试。请求可能产生少量 API 费用，不包含论文、笔记或标注。协议参考 [官方 Chat Completions 文档](https://developers.openai.com/api/reference/resources/chat/subresources/completions/methods/create)；第三方服务的实际兼容性以其实现为准。

成功显示所选模型已响应及耗时；失败区分密钥无效、无权限、模型/接口不存在、限流/额度不足、服务故障、网络/证书或格式错误。不会直接显示服务端原文或模型回复，避免回显密钥。请求总超时 30 秒，响应最多 256 KiB，不跟随重定向。测试中可点「取消测试」或按 Escape；退出软件也会停止测试。不会把网页 HTML 或只有 HTTP 200 的错误响应视为成功。

当前配置按 OpenAI 兼容接口格式设计。Base URL 填写服务商提供的接口基础地址（例如带 `/v1` 的根地址），不是聊天网页或某个完整的请求地址；模型名称使用服务商的模型 ID。支持 HTTP/HTTPS，不接受 URL 中的账号密码、查询参数或片段。需要密钥时必须填写 API Key；本地接口确实无需鉴权时，明确勾选「此接口无需 API Key」。

重新打开弹窗不会显示已有密钥。接口地址不变时，API Key 留空会保留已保存的密钥；修改地址须重新填写对应密钥，防止以后把旧密钥发送到另一服务。显示/隐藏按钮仅切换本次输入。可以修改配置、取消未保存的修改，或清除本机配置。

本机最多可保存 32 套配置。已有的单模型配置会自动出现在列表中，原密钥可继续使用。每套配置独立管理自己的密钥，测试和编辑时只可复用该配置在同一接口下的密钥。全部配置和当前选择由系统加密保存在本机用户目录的 `llm-config.bin`，重启后恢复，可跨本机文献库使用。换电脑后需要重新配置。

配置管理仅提供受主窗口来源检查的桌面 IPC，不向本机 AI HTTP 接口开放密钥读写。不要让用户在聊天、日志或文档里粘贴 API Key，不直接编辑加密文件。

此配置不会改变 MinerU 的本机解析配置，也不会改动 PDF、阅读笔记、标注或引用监控。

验证：`node scripts/run.cjs test` 含加密、密钥保留、接口变更、并发保存、异常保护测试；`node scripts/run.cjs test:model-settings` 用隔离用户目录验证实际弹窗、系统加密、重启保留、取消/清除及布局，可加 `--packaged` 验证发布程序。
