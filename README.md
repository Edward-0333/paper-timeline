# Paper Timeline

GitHub 项目的参考用途、选型和采用情况统一记录在 [GitHub 参考仓库与采用记录](docs/github-references.md)，实际分发组件的许可见 [第三方声明](THIRD_PARTY_NOTICES.md)。

使用过程中遇到的不便、问题和改进想法可持续追加到 [使用体验与改进记录](docs/usage-feedback.md)。

文献详情与 PDF 阅读页可添加个人「精简笔记」，时间线底部可切换展示；PDF 阅读页也可直接管理论文标签。新加入的文献在列表标题前显示绿色圆点，单击查看详情后清除，状态随文献库保存，旧文献不补打圆点。

PDF 阅读页顶部可直接「打开资料文件夹」。文献库自动生成分层 [AI 资料导航](docs/library-ai-index-guide.md)，从库根目录的 `AI-INDEX.md` 逐层定位论文、PDF、笔记及解析资料，随库移动后仍使用相对路径。

文献库采用「每篇论文一个资料文件夹」：PDF、笔记、阅读标注、MinerU 结果和引用记录集中放在 `papers/<资料文件夹>/`。详情「更多操作 → 打开资料文件夹」可直接查找，AI 聊天也以该文件夹为工作目录。旧库自动复制升级，校验后切换索引，原资料保留作恢复备份。详见 [文献库布局与迁移](docs/library-layout-guide.md)。

新增内置 EmbedPDF 阅读器：点击 PDF 图标或「打开 PDF」即可在软件内阅读、高亮、添加下划线、调整颜色与管理批注。标注、页码和缩放自动保存在各论文资料文件夹的 `annotations.json` 中，原 PDF 保持原样，复制文献库时一并携带。引擎及字体随软件提供，可离线使用。详见 [PDF 阅读器说明](docs/pdf-reader-guide.md)。

支持同时保留多篇论文的阅读标签。打开新论文会新增标签，同一篇复用；每个标签固定宽度显示论文名称，长标题省略、悬停查看完整名称，支持横向滚动、独立关闭和切换，分别恢复标注、页码和缩放。

阅读器右上角「AI」打开论文阅读 Agent，使用首页配置的大模型，通过 AI SDK 调用限定于当前论文的工具。可检查资料、等待本机 MinerU 转换、分段读取全文/笔记/标注、关键词查找、查看解析图片和 PDF 原始页面。发送问题后，模型按需调用工具，读取的文字和图片会发送到该模型接口；打开面板本身不联网。侧栏显示执行状态和资料查阅记录，成功对话与引用保存在各篇 `chat.json`，重新打开或换电脑可恢复；草稿只保留在本次运行内存中。停止会取消本轮请求及本轮启动的转换，不停止原已运行的手动转换。详见 [模型配置与论文 Agent](docs/model-api-guide.md)。

个人首页现提供“监控清单对账”：分别显示当前库与账户全部监控，按本地开关对齐当前库，
并逐项转入或停止旧网页订阅。需要两端升级，保留其他文献库和账户的监控，详见
[云端引用监控指南](docs/cloud-monitoring-guide.md)。

Windows 桌面文献库，使用 TypeScript、Electron、React。支持文献整理、时间线及云端引用监控，逐步扩展论文研究 Agent 能力。

## 启动

已打包版本可直接运行 **release/win-unpacked/Paper Timeline.exe**，不需要安装 Node.js。请保留 `win-unpacked` 文件夹的完整内容，不要只移动其中的 EXE。

开发时可在此目录双击 **Start.bat**。启动时会先构建应用，然后打开桌面窗口。

也可以在此目录运行：

```sh
npm install
npm start
```

开发工具需要 Node.js 22.16 或更高版本，推荐 Node.js 24 LTS。启动脚本优先使用当前 Node.js；如果版本过旧，会尝试使用本机 Codex 附带的 Node.js。软件打包后的 Windows 可执行文件不需要另外安装 Node.js。

## AI 工作入口

AI 进入本文件夹时先读取 [AGENTS.md](AGENTS.md)。[ai/capabilities.json](ai/capabilities.json) 提供已实现操作的能力清单、参数、写入与联网标记；[ai/README.md](ai/README.md) 提供调用方式、状态含义和功能边界。

启动新版软件后，可以运行 `PaperAI.cmd call app.status`、`PaperAI.cmd call papers.list`，或通过参数文件重新检索、导入、修改元数据、管理文件夹及添加、编辑、移动、删除彩色标签。运行 `PaperAI.cmd capabilities` 可离线发现功能。命令返回 JSON，操作与界面同步，不直接改写文献库文件。发布目录也附带相同入口，不需额外安装 Node.js。

## 当前功能

- 点击右上角「导入 PDF」，或把一个/多个 PDF 拖入窗口。
- 在后台线程解析 PDF 首页，提取标题、DOI、arXiv 编号并生成首页缩略图。
- 优先通过 arXiv 编号检索，再尝试 DOI/Crossref，最后按标题匹配。所有在线结果还会校验标题。
- 自动显示标题、作者、年份、期刊/会议、DOI、arXiv 编号、摘要与元数据来源。
- 内容哈希去重，复制 PDF 到本地文献库，保留原文件。
- 列表采用三栏布局：左侧文件夹，中间论文表格，右侧详情与元数据；顶部统一提供搜索、核对状态筛选和右上角视图切换。
- 左侧包含全部文献、未分类和自建文件夹；支持新建、重命名、删除文件夹。右侧「所属文件夹」可给论文归类，在文件夹中导入 PDF 会直接归入当前文件夹。当前每篇论文归属一个文件夹，支持平级文件夹。
- 表格显示标题、标签、评分、被引数、作者、发表日期、期刊／会议和附件等信息。「被引数」在评分右侧，沿用详情页本地已同步、去重后的引用文献数量；未取得数据时显示「—」，成功取得零条时显示「0」，暂停监控后保留历史数量。点击列名可按数值升降序排列，未知数据始终在末尾；列宽可拖动并记忆。标签沿用各标签的背景色，始终单行排列，超出列宽的部分隐藏，长名称显示省略号；悬停标签单元格或打开详情可查看全部标签，无标签时显示短横线。在详情中修改标签后，列表同步更新。默认最近导入在前，点击标题、作者、发表日期或期刊／会议列标题也可排序；上下方向键切换条目，双击或回车打开 PDF。
- 将鼠标放在表头列分隔线上可左右拖动，调整左侧列的宽度，其他列保持不变；标题始终单行显示，过长时显示省略号，悬停可查看完整标题；标签保持单行，列宽变化不再使标签换行或增高行高。拖动结束不保留选中边框。列宽在本机自动记住，切换视图或重启后保留。双击分隔线恢复该列默认宽度；分隔线获得键盘焦点后，左右方向键每次调整 10 像素，Shift 加速为 50 像素，Home 恢复默认。拖动时按 Esc 可取消本次调整。表格超过窗口宽度时可横向滚动。
- 可切换「列表 / 时间线」，并记住上次选择。时间线采用横向画布，论文按发表时间从左到右、由早到晚排列，卡片交错放置在轴线上下，用连线连接对应日期；搜索和筛选同样有效。
- 时间线卡片按标题内容自动调整宽高：短标题更紧凑，长标题达到宽度上限后换行并增高，完整显示标题。卡片间距、连线与画布范围随实际尺寸调整。
- 画布底部点击「新增时间线」，会增加一个独立的「标签筛选」方框，选好标签后显示该条线的论文。每条线独立保存标签条件和位置，同一篇论文可以出现在多条线上。拖动左侧方框或上方的移动手柄，可移动整条线；点击其上方垃圾桶删除该线，保留全部论文与标签。可以删除所有时间线，再重新新增。移动手柄也支持方向键，每次 10 个画布单位，按住 Shift 每次 50 个。布局和筛选条件重启后保留。
- 每条时间轴最左侧支持多选标签。选中的标签会在方框内以「彩色圆点＋标签文字」逐行显示，圆点沿用标签颜色；长名称自动换行，方框随内容调整大小，多选时显示交集或并集提示。「按标签筛选」右侧的滑动开关向左为「交集」（默认），显示同时具有全部所选标签的论文；向右为「并集」，显示具有任一所选标签的论文。可拖动开关或点击两侧文字切换，勾选后立即更新，选择框保持打开，底部显示已选标签数与匹配论文数。取消全部勾选或选择「全部论文」恢复当前范围中的全部论文。标签较多时可以搜索名称，搜索不清除已选标签；每个标签旁的数量是当前搜索、核对状态和文件夹范围内带该标签的论文数。相同名称不区分大小写，使用全库统一颜色并归为同一选项；标签筛选仅影响时间线，列表视图保持原有范围。
- 右键点击时间线论文卡片，选择「添加标签」后输入文字并选择背景色，标签默认贴在卡片下边框。按住标签拖动，可沿论文框四周调整位置，标签始终与边框接触，松开后自动保存位置。右键点击标签可编辑或删除；每篇最多 32 个，文字为 1–80 字符，同篇不允许重名（不区分大小写）。文字、颜色和位置保存到本地，重启和重新检索后保留，不改变论文核对状态或元数据来源。
- 时间线默认使用整个主区域，点击卡片展开右侧详情，点击「收起详情」恢复大画布。同一篇论文出现在多条时间线上时，只选中刚才点击的那一处，打开详情后保持在该条线上；关闭标签菜单或编辑框也返回原来的论文框。按住鼠标中键（滚轮键）可从画布任意位置平移，包括论文框、标签和筛选框；左键仍用于选择论文、拖动标签和单条时间线。Ctrl + 滚轮或底部按钮缩放，支持一键适应画布、恢复 100%；画布获得焦点后也可以用 `+` / `-` / `0` 缩放或总览。
- 发表日期支持年、年-月、年-月-日三种精度；未知日期单独放在「日期待补充」区域，不用导入时间替代。旧文献只有年份时直接按年份显示，可通过「重新检索」获取更完整的日期，也可在编辑元数据中补充。时间轴间距为保证卡片清晰而调整，不代表按比例的时间跨度。
- 右侧「更多操作」（三个点）包含编辑元数据、重新检索、打开资料文件夹与查看来源；原文件信息默认折叠。
- 点击论文后，右侧详情中的「标签」区域显示已有彩色标签。点击「添加标签」可输入文字并选择背景色，点击标签文字可编辑，点击标签旁的 × 可从该篇论文移除。修改自动保存，并与时间线标签和筛选同步；编辑标签不会改变它在论文边框上的位置。
- 全库同名标签统一颜色，名称去除首尾空格且不区分大小写。新增已有名称时自动沿用其颜色；编辑同名标签的颜色会同步到全库，界面显示提示。改名只改当前标签，改为已有名称时沿用目标颜色；删除和移动仍只影响当前标签。旧库启动时按同名标签最常用的原有颜色统一，次数相同按大写 HEX 字典序选择；一次原子保存并备份原索引，保留标签文字、ID、位置及其他资料。PDF/MD 文件标签的颜色不受影响。
- 网络中断时保留本地解析结果；无法可靠匹配时标记待核对。
- 关闭后保留文献库，重启时继续未完成的任务。

文件夹作为文献分类保存，不会额外复制或移动 PDF。删除文件夹时会保留论文和 PDF，并将其中的论文转为「未分类」。旧版文献库可直接加载，已有论文默认显示在「未分类」。选择文件夹后切换到时间线，也只显示该文件夹中的论文。

元数据检索不需要大模型密钥。第一版使用文献数据库返回的真实记录；未接入大模型推测或生成元数据。

时间线日期规则：Crossref 优先采用 `published`，缺失时依次采用 `published-online`、`published-print` 的有效日期，保留原始精度（[Crossref 日期说明](https://community.crossref.org/t/date-types-in-the-rest-api/15118)）。arXiv 使用 API 的 `published` 或页面明确列出的 v1 提交日期，表示预印本首次提交；不会使用修订日期（[arXiv API 说明](https://info.arxiv.org/help/api/user-manual.html#3321-title-id-published-and-updated)）。缺少月或日时不补造 1 月 1 日；同年内仅有年份的记录排在日期更完整的记录后面。同一天按标题排序。

## 数据与隐私

### 引用监控

论文详情中部的「引用监控」开关默认关闭。个人首页登录后，开关请求保存到本库，连接时提交给服务器。服务器合并所有有效订阅，每天北京时间 08:00 开始依次拉取，论文之间默认间隔 10 秒。桌面完全退出后云端继续；重新打开并登录后恢复结果同步。

Paper Monitoring 服务器向 OpenAlex 和 Semantic Scholar 查询引用该论文的文献。桌面只与用户指定的服务器同步，支持分页、跨来源去重和历史保留。界面显示已保存数量、最近更新、下次检查和异常原因，点击「数据目录」可打开本篇论文的引用目录。一个来源失败时保留另一个来源的结果；未找到目标论文、无引用、网络失败分别处理。关闭请求同步成功后暂停当前库订阅并保留历史数据。

数据位于 `library/papers/<资料文件夹>/citations/citations.json`，包括目标论文、最近拉取时间、来源状态和引用记录，更新采用临时文件原子替换并保留 `.bak`。此子目录属于对应论文的资料文件夹，引用条目不会自动入库。本阶段仅保存 JSON，不下载论文原文；目录可供后续附件功能扩展。「复制当前文献库」会一并复制、校验引用目录。

数据库密钥 `OPENALEX_API_KEY` 和 `SEMANTIC_SCHOLAR_API_KEY` 只配置在服务器。限流或鉴权失败会显示来源错误并在下一轮重试，不把失败显示为“零引用”。引用数据仅反映外部数据库当时已收录的结果。

顶部「文献库设置」明确显示当前完整路径和论文数量，可打开该文件夹，并提供三种操作：

- **选择已有文献库**：选择包含 `library.json`、`papers/` 和 `sync/`（如有）的文献库文件夹，适合换电脑后继续使用。
- **复制当前文献库到新位置**：选择一个空文件夹，复制当前索引及普通备份、完整 `papers/`（含额外普通文件）与 `sync/`，逐文件校验后改用新位置；原库保留。旧布局历史目录、升级前索引备份、迁移暂存与临时接口凭据不会复制。
- **新建空白文献库**：选择空文件夹，创建独立的新库。

选择后会显示目标路径，点击「应用并重启」生效并记住位置。导入或检索尚未完成时不能切换；现有文件夹不会被覆盖或自动合并。保存的位置失效时，启动会提示重新选择或使用默认位置，不会在失效路径上悄悄创建空库。

换电脑时先退出软件，复制完整软件文件夹和整个文献库文件夹，在新电脑「文献库设置 → 选择已有文献库」中选中后应用，再重新登录同一账户。软件本身不包含用户文献；云同步仅限订阅和引用元数据，不包含 PDF 或 MD 原文。

未自定义时，默认目录为本项目根目录中的 `library/`，即 `paper-timeline/library`。源码启动与项目内 `release/win-unpacked/Paper Timeline.exe` 使用同一份文献库，不受启动时工作目录影响。也可以点击顶部的文件夹图标「本地文献库」打开。

如果把完整的 `win-unpacked` 文件夹复制到项目之外单独运行，则默认使用 EXE 同级的 `library/`。自定义位置保存在默认库父目录的 `library-location.json`，软件目录内的库使用相对路径，随整个目录移动后仍可使用。高级用法可设置环境变量 `PAPER_TIMELINE_DATA` 指定独立的数据与设置根目录，默认库为其下的 `library/`，界面选定的新位置也只记在该根目录中。

旧版 `library.json` 的版本 1 布局在新版打开时自动升级为版本 2。原索引另存为 `library.pre-paper-folders-v1.json`，源资料保持不变；复制并校验后才切换索引，成功后清理本轮安全的暂存副本。旧目录继续保留用于恢复，不自动删除。原先从旧用户数据目录搬到项目目录的 `scripts/migrate-library.cjs` 是不同用途的历史脚本，不是这次结构升级的必要步骤。

```text
library/
  library.json                   全库索引，version: 2；元数据、标签、评分、分类和时间线
  library.json.bak               上一次索引保存的备份（如有）
  papers/
    <简短标题>__<ID前12位>/        稳定资料文件夹，修改标题时不重命名
      original.pdf               原文（如有），内容哈希仍用于去重与校验
      notes.md                   Markdown 阅读笔记（如有）
      annotations.json           PDF 标注、页码和缩放（如有）
      parsed/                    全文转换索引及历次成功结果（如有）
      citations/                 引用记录及备份（如有）
  sync/                          账户绑定、库编号与引用同步进度（不含凭据）
```

此阶段采用版本化 JSON 文件、临时文件原子替换和备份来持久化，未引入原生数据库编译依赖。后续文献规模扩大、加入全文索引时，可以替换 `electron/library.ts` 的存储实现为 SQLite。

元数据检索向 arXiv、Crossref 发送论文编号或标题；引用监控把公开书目元数据和开关发送给登录的 Paper Monitoring 服务器，均不上传 PDF。PDF 解析在独立线程进行。渲染界面关闭 Node.js 集成，开启上下文隔离与沙箱，通过有限 IPC 接口操作文献库。

摘要可能来自数据库，也可能从 PDF 首页提取；PDF 排版复杂时，提取结果仍可能含断词或上标位置误差，请以原文为准。

## 当前限制

- PDF 阅读器本身不提供 OCR；扫描件可通过详情中的本机 MinerU 转换获取可读全文。加密 PDF 需要先解密。
- 单个 PDF 上限 100 MB，单次拖放最多 200 个文件。
- 外部数据库可能缺少摘要、出版信息，或因网络/限流暂时不可用。
- arXiv 论文优先保留预印本信息与首次发表年份，不把预印本年份当作期刊出版年份。
- 尚未实现全文 AI 问答、引用插入、PDF/MD 云备份和自动更新。

## Markdown 笔记与 Excel 阅读记录

列表的「MD 笔记」列用紫色文档图标表示已有笔记，点击会用系统默认软件打开库中副本；短横线表示没有笔记。详情中的「添加笔记」可以选择 UTF-8 `.md` 文件（最大 10 MB），复制到文献库。每篇一份，重复添加相同原文件不会覆盖库中编辑；编辑笔记请打开库中副本。

通过 AI 接口导入的 Excel 等阅读资料显示在详情「阅读记录」中，展开可查看原始概述、重要性、作者单位等字段。这些数据随文献库一起保存，不替代在线检索元数据。`notes.attach`、`notes.get` 和 `papers.setReadingRecord` 的参数见能力清单。

## PDF / MD 文件标签

列表的红色 PDF 图标点击后用内置阅读器打开库中原文，阅读器另有「默认软件打开」。时间线中，存在的 PDF 和 MD 会自动显示为论文边框周围的红色、紫色文件标签。按住拖动时始终贴边，论文主框保持不动；点击打开相应文件。文件标签不可删除或编辑，不参与分类筛选，位置会保存并随文献库迁移。

## 论文评分

在文献详情的「评分」中点击第 1–5 颗星设置评分，点击「清除评分」恢复未评分。列表在「标签」后显示「评分」列，时间线在论文框内作者右侧显示黄色星星。同一篇论文在多条时间线上共享评分，评分随文献库保存、复制，重新检索元数据也会保留。

`papers.setRating {id,rating}` 设置评分，`rating` 只能是 1–5 的整数或 `null`（清除）。返回保存后的论文；`papers.list` / `papers.get` 的 `rating` 字段表示星级，未评分时省略。操作不联网、不修改元数据来源和核对状态，不要通过 `metadata.update` 修改评分。

评分界面回归：先构建，再执行 `node scripts/run.cjs test:ratings`。该测试使用内存数据和 Chrome，不接触正式库；可通过 `PAPER_TIMELINE_BROWSER` 指定浏览器路径。

## 时间线视图记忆

缩放比例和画布中心位置会按文献库路径保存在本机。切换到列表再返回、重新打开软件或窗口尺寸变化后，继续上次查看的位置。没有保存记录时首次进入自动适应画布；也可随时点击「适应画布」重新总览，新的视图同样会保存。新增或删除时间线时仍会自动展示整体布局。视图偏好不写入 library.json，不会改动论文或时间线数据。

视图记忆回归：先构建，再运行 `node scripts/run.cjs test:timeline-viewport`，使用独立浏览器上下文和内存文献库；默认 Chrome，可用 `PAPER_TIMELINE_BROWSER` 指定路径。


## 云端引用监控与个人首页

启动默认显示个人首页，统计当前整个文献库的论文、PDF、Markdown 笔记和监控数量。首页显示服务器最近成功抓取、本地最近完整同步、当轮去重后的新增引用、待同步开关和云端异常数量。未连接时明确显示缓存状态。

「同步概况」以水平柱状图比较本库云端已确认与账户全部监控论文，云端待抓取和未完整更新分别展示；这不是每日抓取进度，不推算成功数。新增引用、待同步开关和旧网页待处理用数字卡，最近抓取与同步用独立时间记录。监控按论文去重计篇，旧网页待处理按订阅条目计项；缺失数据不会显示成零，断连可继续查看上次同步的缓存。

点击首页的统计卡片可直接查看相应文献：

- **本地论文**：进入文献库，显示全部文献，保留原来的列表/时间线视图偏好。
- **PDF 原文**：打开仅包含实际 PDF 附件的论文列表。
- **Markdown 笔记**：打开仅包含实际 Markdown 笔记的论文列表。
- **本库监控已开启**：打开与首页监控计数一致的论文列表；尚未迁移的旧本地监控不计入。

后三项在顶栏「文献库」右侧打开标签页，宽度随文字长度收缩，只保留内边距和关闭按钮空间。各页可单独搜索、排序、调整列宽及打开文件。单击论文行，在本页右侧查看完整文献详情，可继续管理标签、评分、监控和附件，与文献库同步。顶部「个人首页」「文献库」及动态标签使用一致的文字、背景和激活样式；PDF 论文阅读标签仍为固定宽度，长题目省略。重复点击复用已有标签；列表标签与 PDF 阅读标签按打开顺序排列，可分别关闭，切回文献库保留原来的筛选。标签页与各自搜索保留至关闭或退出软件。桌面回归使用隔离测试库：`node scripts/run.cjs test:home-collections`，发布版附加 `--packaged`。

个人首页「云端引用监控」改为与「API 大模型」相近的紧凑卡片，显示连接状态及账户摘要；点击连接管理入口后，在弹窗中填写 Paper Monitoring 的 HTTPS 地址、用户名或邮箱、密码，或管理已登录连接。首页不再常驻登录表单；立即同步、退出登录及旧本地监控迁移仍需明确操作。关闭弹窗不退出账户，不停止同步或云端任务。登录后本库绑定服务器和账户，换账户请使用另一个文献库。密码不保存；桌面会话由操作系统加密，放在本机用户目录，不能随 library 拷贝。换电脑后重新登录同一账户。退出登录只断开桌面同步，不停止服务器任务；网页服务概览可撤销设备会话。

详情中的引用监控开关保存个人订阅。服务器按所有用户的有效订阅合并总表，每天北京时间 08:00 开始依次拉取，论文之间默认间隔 10 秒；桌面运行且登录后约每分钟同步。离线开关保存在本库，显示待同步；关闭请求成功到达服务器后才生效。其他用户或文献库仍开启的订阅继续监控。旧版本已开启的本地监控不会自动上传，需在首页明确点击迁移到当前账户。

本地 OpenAlex / Semantic Scholar 抓取及定时器已移除。arXiv / Crossref 单篇元数据检索仍可使用。引用结果保存到 library/papers/<资料文件夹>/citations/citations.json，失败不会清空历史数据，不自动下载 PDF，也不自动运行 AI 分析或加入主列表。

AI 可用 cloud.status 查询无凭据的状态、cloud.sync 触发一次同步、citations.setMonitoring {id,enabled} 管理单篇开关，以及 citations.get {id,offset?,limit?} 分页读取本地记录。首次登录、退出和旧监控批量迁移由桌面界面提供。不要默认开启全部文献。开关保存成功不等于服务器已确认，须检查 pending / error。

复制文献库必须包含 library.json、完整 papers/ 和 sync/。sync/cloud.json 保存账户绑定、库编号和同步进度，不含凭据。复制同一库用于换电脑应停止旧电脑写入；不要在两台电脑同时修改同一个库的独立副本。界面复制会等待同步结束并校验文件。

测试使用隔离测试库，执行 node scripts/run.cjs test；云端连接流程见 docs/cloud-monitoring-guide.md。
